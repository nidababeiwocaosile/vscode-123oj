# vscode-123oj

轻松的让你在 VS Code 上使用[青岛123编程](https://www.kids123code.com/)oj。

## 使用说明

请参考`Github`上的[wiki](https://github.com/nidababeiwocaosile/vscode-123oj/wiki)页面。

## 完成功能

* 查看比赛列表
* 查看题目
* 登录账号
* 登出账号
* 提交代码
* 提交代码后查看自己评测
* 一键测评题目小样例

## 考虑开发功能

* NOI提交
* 打开带密码比赛
